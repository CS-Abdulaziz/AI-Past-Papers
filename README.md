# Artificial Intelligence Past Papers

Interactive practice for **CS1360 Artificial Intelligence** (CS361): 216 solved past exam questions for the midterm, sorted by lecture chapter.

**Use it online: https://cs-abdulaziz.github.io/AI-Past-Papers/**

- Questions come from past midterms, finals and quizzes (2021–2026), including the latest quiz (1st semester 2026).
- Each question is solved from the lecture slides in [`slides/`](slides) and shows the slide number where the answer is.
- Chapters: 2 Intelligent Agents · 3 Uninformed Search · 4 Informed Search · 5 Games · 6 CSP. Logic, probability, Bayesian network and machine learning questions from older exams are not included.
- One question per page with Show solution, Prev / Next, Shuffle, and a "Review my mistakes" step when you finish.

## Run it locally

Open [`site/index.html`](site/index.html) in any browser. No install needed.

## Folders

| Folder | Contents |
|---|---|
| `site/` | The website (`index.html`, `questions.js`, `img/`) |
| `slides/` | Lecture slides for Chapters 2–6 |
